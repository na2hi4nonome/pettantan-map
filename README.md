# 食べて歩いてぺったんたん 非公式マップ

鳥取県倉吉市で開催中のスタンプラリー「食べて歩いてぺったんたん」の参加店舗を、地図と一覧でまとめたファンサイトです。

**公開サイト:** https://na2hi4nonome.github.io/pettantan-map/

> ※本サイトはファンが作成した非公式サイトです。スタンプラリーの最新・正確な情報は公式サイト（倉吉ひなビタ♪応援団: http://kurayoshi-moks.net/ ）をご確認ください。

## 概要

- 開催期間：2026年5月30日（土）〜2027年3月31日（水）
- 対象エリア：鳥取県倉吉市
- 掲載店舗：70件（`data/spots.geojson`）

## 主な機能

- **マップ表示** — Leaflet を使い、参加店舗を地図上にマーカー表示（マーカークラスタリング対応）
- **現在地追従** — 現在地を取得して、近い店舗を探せる
- **絞り込み・検索** — 店舗カテゴリ／スタンプ種別での絞り込み、店名検索
- **店舗一覧** — トップページに全店舗を一覧表示
- **スタンプ進捗** — 押したスタンプの進み具合を表示

## 技術スタック

- HTML / CSS / JavaScript（フレームワークなし）
- [Leaflet](https://leafletjs.com/) 1.9.4 + Leaflet.markercluster 1.5.3
- データ形式：GeoJSON
- ホスティング：GitHub Pages

## ファイル構成

```
.
├── index.html          # トップページ（概要・遊び方・店舗一覧）
├── map.html            # マップページ
├── css/
│   └── style.css       # 共通スタイル
├── js/
│   ├── map.js          # 地図の初期化・マーカー・現在地追従
│   ├── list.js         # 店舗一覧の描画
│   ├── filter.js       # 絞り込み・検索
│   ├── stamps.js       # スタンプ進捗の管理
│   └── labels.js       # 表示ラベルの定義
├── data/
│   └── spots.geojson   # 参加店舗データ（70件）
└── img/
    └── stamp.png       # スタンプ画像／ファビコン
```

## ローカルで確認する方法

店舗データは `fetch` で読み込むため、`index.html` を直接ダブルクリックで開くと一覧が表示されない場合があります。ローカルサーバー経由で開いてください。

```bash
# リポジトリのフォルダで実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
